Project

    Proxmox

    A homelab virtualization setup used to create, run, and manage multiple virtual machines from one Proxmox server.

    This project focuses on building a Proxmox virtualization server for my homelab. I installed Proxmox, created virtual machines, tested different operating systems, and learned how to manage compute, storage, and networking from one platform. It gave me hands-on experience with virtualization and server administration.

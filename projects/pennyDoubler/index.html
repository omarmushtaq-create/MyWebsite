    Penny Doubler

    A Python project that calculates how quickly a penny grows when it doubles each day, showing exponential growth through a simple, clear program.

    This project is a simple Python program that shows how fast exponential growth can happen. It starts with one penny, doubles the value every day for 30 days, and calculates the final total. Building it helped me practice variables, loops, math operations, and clear problem solving.

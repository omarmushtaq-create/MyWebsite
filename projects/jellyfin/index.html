Jellyfin

A self-hosted media server that allows users to stream and manage their media collection from anywhere.

About Jellyfin

Jellyfin is a free and open-source media system that puts you in control of managing and streaming your media. It is an alternative to the proprietary Emby and Plex, to provide media from a dedicated server to end-user devices via multiple apps.
